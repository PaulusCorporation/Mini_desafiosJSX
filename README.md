# ⚛️ Mini Desafios React — UNIESP

Projeto com os 12 mini-desafios da disciplina de Front-end (Partes 1 e 2 do material).

## 🚀 Como rodar

```bash
npm install
npm run dev
```

Acesse [http://localhost:5173](http://localhost:5173)

## 📋 Mini-desafios

| # | Componente | Conceito |
|---|---|---|
| 1 | `MeuPerfil` | Componente simples com JSX |
| 2 | `BotaoAlerta` | Primeiro `onClick` |
| 3 | `TrocaTexto` | `useState` |
| 4 | `LogoUniesp` | Imagens em `public/` |
| 5 | `Filme` + `ListaDeFilmes` | Props e `.map` |
| 6 | `MaiorDeIdade` | Ternário e Fragments |
| 7 | `CartaoDestaque` | CSS Modules |
| 8 | `EcoTexto` | Input controlado com `onChange` |
| 9 | Site com 2 páginas | React Router |
| 10 | `DataDeAgora` | `useEffect` |
| 11 | API de filmes | json-server |
| 12 | `ListaDeFilmes` | Axios + json-server |

## 🛠️ Tecnologias

- React + Vite
- React Router
- Axios
- JSON Server
- CSS Modules
